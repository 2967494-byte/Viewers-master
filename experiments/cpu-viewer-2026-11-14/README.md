# CPU viewer — остановленный отдельный эксперимент

14 ноября 2026 пользователь отказался от использования CPU/Canvas fallback.

Сюда перенесены исходники и тесты эксперимента с сохранением исходных путей, а также его описание. В `integration-snapshot/` лежат снимки трёх общих файлов до удаления экспериментальной интеграции. Относительные импорты экспериментальных файлов рассчитаны на прежнее расположение; это архив, а не самостоятельный собираемый проект.

Основное приложение больше не импортирует CPU viewer или его worker, не содержит автоматического CPU-перехода и не обрабатывает `render=cpu`. Файлы вне исходников приложения и корней Jest. Общий тестовый runner их не запускает. Архив не копируется в dist.

Документ `docs/specs/viewer-cpu-fallback-2026-11-14.md` внутри архива описывает состояние эксперимента на момент остановки, а не текущую работу просмотрщика. Не возвращать интеграцию без отдельного запроса пользователя.
