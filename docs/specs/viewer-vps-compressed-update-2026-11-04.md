## Что изменено

1. Облачный просмотр по умолчанию читает только опубликованную сжатую серию из `hot/.../appt_.../_viewer/`.
2. Точка входа — `representations.json`, затем manifest и точные индексы готовых серий. Нет сканирования исходных DICOM или поиска их индекса при отсутствии результата.
3. Проверяются schema/source version, готовность, срок хранения, полнота индекса и отсутствие дублированных инстансов. Относительные пути ограничены опубликованным поколением.
4. Подготовлен маршрут `/3dviewer/v/:token` для будущей CRM. Старое небезопасное декодирование base64 с произвольным prefix удалено. Требуется авторизованный ответ resolver нового формата.
5. Разрешения CRM — временные подписанные GET URL только на конкретные объекты сжатой версии. Они остаются в памяти вкладки; постоянные ключи бакета не нужны врачу. При отсутствии разрешённого URL SDK-путь с общими ключами не используется.
6. Форма ручной S3-проверки поясняет требование готовой сжатой серии. Локальная загрузка файлов/папок сохранена.
7. Для `/3dviewer/v/` Nginx отключает access log и использует no-store. Referrer-Policy — no-referrer; COOP/COEP сохранены.

Структура файлов, JSON-схемы, подписанные URL и ответ будущей CRM описаны в [контракте v1](viewer-compressed-hot-contract-v1.md).

## Что не изменялось

CRM, её исходники/БД/сервер/API, Orbital Uploader, S3 bucket, lifecycle/CORS и медицинские данные не изменены.
Автоматическая служба сжатия ещё не реализована. В существующем HOT этим релизом не создаются новые сжатые файлы.
Пока служба не публикует `_viewer/representations.json`, а CRM не выдаёт новый ответ resolver, облачное открытие таких исследований сообщает о недоступности/подготовке. Это ожидаемое поведение.

## Доступ и откат

Nginx по-прежнему слушает только `127.0.0.1:8080`. Публичные порты/DNS/HTTPS не менялись.
На рабочем компьютере запущен скрытый SSH-туннель: `http://127.0.0.1:18080/3dviewer/`.
Туннель привязан только к loopback; пароль не сохранён в его исходнике или отчёте.

Для отката статической сборки на VPS:

```bash
ln -s /var/www/orbital-viewer/releases/20261028T201217Z-7d37627 /var/www/orbital-viewer/.rollback-20261104
mv -Tf /var/www/orbital-viewer/.rollback-20261104 /var/www/orbital-viewer/current
```

Текущий Nginx совместим с предыдущей сборкой. До изменения дополнительно сохранены копии site и headers snippet с суффиксом `.backup-20261104T125450Z-compressed-v1`.

Артефакт и подробные технические результаты локально: `tmp/viewer-compressed-release/` (игнорируемый каталог).
