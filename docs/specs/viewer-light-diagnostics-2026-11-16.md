# Лёгкая диагностика открытий просмотрщика

Состояние: локальная реализация, без выкладки на бой. Расширяет существующую статистику открытий на `/admin/vms`. Качество, размеры текстур и алгоритм выбора графического профиля не меняются.

## Два уровня

- **Обычный запуск:** оценка выделенных текстур объёма (текущая/пиковая), исходного объёма, число выделений/освобождений, пиксели полотен, количество отрисовок, полученные байты DICOM, время загрузки и декодирования, ошибки. В памяти хранится кольцо последних 40 событий, в обычный отчёт история действий не включается.
- **Сбой:** в следующий отчёт автоматически включается это кольцо — последние изменения режима, фильтра, инструмента, раскладки, панорамы/3D, видимости вкладки, выделения/освобождения и ошибок текстур. Это ретроспективный отчёт; сбор дорогих измерений автоматически не запускается.
- **Ручная углублённая проверка:** `?viewerDiagnostics=deep` в исходной ссылке `/3dviewer/v/<token>`. Дополнительно наблюдаются долгие задачи основного потока и время вызова нативной отрисовки. При наличии поддерживаемого API и изоляции страницы память измеряется асинхронно, первый раз не ранее минуты и далее не чаще раза в пять минут. Измерение не запускается в скрытой вкладке. Режим графики не меняется; это отдельный параметр от прежнего диагностического профиля 64 МиБ.
- **Контрольный запуск:** `?viewerDiagnostics=off` отключает весь новый сбор, оставляя прежнюю статистику открытия для сравнения.

## Отправка и изоляция

- Загрузка и отрисовка не ожидают ответов системы отчётов. Никаких дополнительных чтений пикселей, `gl.getError` или `gl.getParameter` в цикле отрисовки.
- Во время открытия используются существующие отчёты по вехам. Действия инструментами не вызывают запросов. После открытия — дополнительная сводка раз в 60 секунд, только пока вкладка видна.
- При сетевой ошибке, 429 или 5xx — максимум три повтора с интервалами 30/120/300 секунд. Передаётся последнее состояние, очередь отчётов не растёт. При исчерпании попыток дополнительный сбор выключается. 401/403 и другие постоянные ошибки прекращают отправку сразу.
- У каждого запроса тайм-аут 5 секунд. Токен CSRF обновляется после 50 минут. Старый сервер без `diagnosticsVersion: 1` получает прежний формат, дополнительный сбор отключается.
- Тело JSON ограничено 24 КиБ. Клиент при превышении отправляет прежнюю сводку без дополнительной диагностики. Старые тела без `diagnostics` сохраняют предел 8 КиБ. Сервер проверяет все вложенные ключи, типы, числовые пределы и закрытые перечни событий/значений.
- Хранится один последний JSON на открытие в существующей таблице. Дополнительной таблицы событий и миграции нет. Обновление старым клиентом не удаляет уже полученную диагностику. Старые последовательности не затирают новые данные.
- Сохраняются действующие cookie, CSRF, привязка к владельцу и проверка доступа к исследованию. В `Referer` POST передаётся только origin, без кода запуска. Ссылки S3, пиксели, теги DICOM, координаты и тексты врача в диагностику не попадают.

## Как читать показатели

- UUID профиля браузера — случайный локальный идентификатор для сопоставления повторных сбоев. Это не идентификатор физического компьютера; другой браузер/профиль имеет другой UUID.
- Число вкладок через `BroadcastChannel` — приблизительное число просмотрщиков на том же origin в одном профиле. Другие сайты и программы не видны; при заморозке вкладки оценка может устареть.
- Размеры текстур — сумма известных выделений объёма, не вся видеопамять процесса и не свободная VRAM. `sourceBytes` — оценка одного исходного объёма, не полный расход ОЗУ.
- Время загрузки/декодирования суммирует параллельные операции, поэтому может превышать длительность открытия. Полученные байты относятся к DICOM в загрузчике, без индексов, HTTP-заголовков и повторов внутри транспорта.
- `draws` — число выполненных вызовов нативного рендера, не FPS. В ручном режиме `drawMs` — время вызова на CPU, не время завершения работы GPU.
- Замер памяти страницы зависит от браузера. Недоступное значение — `null`, не ноль. Общую свободную ОЗУ, занятость/температуру GPU и вкладки других сайтов обычная веб-страница не определяет.
- Счётчик байтов отчётов отражает тела JSON без HTTP/TLS, текущая отправка видна в следующем отчёте. Жёсткое завершение процесса браузера не гарантирует последний отчёт.

- Новые проверки покрывают ограниченное кольцо, освобождение текстур, отсутствие дорогих измерений в базовом режиме, очистку таймеров, ограничение повторов и независимое подтверждение открытия при недоступном сервере отчётов.
