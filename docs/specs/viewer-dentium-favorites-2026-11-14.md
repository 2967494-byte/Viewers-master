## Интерфейс

По умолчанию весь каталог. Слева доступны «Все импланты», «Избранное», производители и линейки. Звёздочка у каждой модели добавляет **типоразмер**, а не производителя целиком. При любых фильтрах сначала отображаются соответствующие им избранные, потом остальные. Нажатие звёздочки не выбирает и не устанавливает имплант.

Избранное сохраняется в CRM для текущей учётной записи. Не зависит от пациента или исследования. На другом компьютере загружается после входа и открытия библиотеки. В браузере только временное состояние; прежний общий localStorage не используется и не переносится врачу автоматически. Закрытие браузера список не удаляет. У кабинета клиники общая учётная запись имеет общий список.

Клиент GET `/api/viewer/implant-favorites`, POST на тот же адрес с `{accountKey, modelId, favorite}` и CSRF. Серверный контракт, таблица и порядок выкладки описаны в `patient_accounting_system/docs/viewer-implant-favorites.md`. Пока API недоступен, нельзя добавлять звёздочки, но каталог, фильтры и установка продолжают работать. Ошибки сохранения явно показаны, успешный вид звёздочки только после подтверждения сервера.
