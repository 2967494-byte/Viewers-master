# Навигация от автопанорамы к MPR

В режиме перемещения щелчок или перетаскивание левой кнопкой по автопанораме
выбирает общую физическую точку для аксиального, коронального и сагиттального
срезов. Предварительно активировать окно не требуется.

## Геометрия

- Горизонтальная координата — расстояние вдоль **текущей** дуги построения.
- Вертикальная — высота относительно дуги, с учётом `raster.topMm` после
  удаления пустых строк. Используется та же геометрия, что при реконструкции.
- Выбранная точка находится в середине толщины слоя панорамы. Проекция
  объединяет несколько глубин; выбор не является определением точной глубины
  каждой видимой структуры. Её уточняют на срезах.
- Допустимая высота ограничена пересечением выбранной колонки с исходным
  объёмом через world-to-index transform. Колонки вне объёма игнорируются.
- Обновляется штатный `CrosshairsTool.setToolCenter`: три плоскости перемещаются
  по своим нормалям. Их ориентация, масштаб и перемещение внутри плоскостей
  сохраняются. Существующая обратная связь обновляет маркеры на панораме.
- После редактирования применяется новый snapshot; устаревший snapshot или
  несовпадение объёмов / FrameOfReference отклоняются.

## Управление и ресурсы

- Pointer capture поддерживает непрерывный drag; старт в полях `object-fit`
  игнорируется, выход за изображение при удержании ограничивается его краями.
- Учитываются реальные CSS-размеры картинки, включая масштаб браузера.
- Частые движения объединяются через requestAnimationFrame. Навигация не
  перестраивает панораму, не декодирует снимки и не делает запросы S3.
- Лупа и измерительные инструменты не перемещают срезы через панораму.
- В редакторе сохранено прежнее управление. Двойной щелчок не меняет раскладку.

## Проверка

`panoramaNavigation.test.ts`: текущая/обратная дуга, обрезка по высоте,
обратное положение маркеров, границы объёма, наклонная геометрия, поля
изображения, дробный масштаб браузера и невалидные входные данные.

Браузерная проверка на синтетической серии: щелчок, непрерывный drag,
совпадение общей точки с тремя плоскостями, сохранение масштаба и ориентации,
режим лупы, изменение размеров окон. Результаты хранятся в отчёте релиза.

Полная регрессия: 41 набор, 295 тестов успешно, 1 пропущен. Дополнительно
Escape обрабатывается в capture-фазе окна: обработчик горячих клавиш OHIF
больше не блокирует возврат из увеличенного MPR. Проверяется фактический
возврат размера окна, а не только сохранение координат.
